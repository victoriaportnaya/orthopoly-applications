# Orthopoly Applications

The public website and documentation for Orthopoly Applications, a Python library for training and numerical applications with orthogonal polynomials.

Website: https://victoriaportnaya.github.io/orthopoly-applications/

The site is plain HTML, CSS, and JavaScript. GitHub Pages publishes this repository from the `main` branch root. The [use-case guide](docs/use-cases.html) covers six practical workflows. The downloadable Python wheel and source archive are in `downloads/`.
