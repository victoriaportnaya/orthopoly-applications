# Orthopoly Applications

The public website and documentation for Orthopoly Applications, a Python library for training and numerical applications with orthogonal polynomials.

Website: https://victoriaportnaya.github.io/orthopoly-applications/

The site is plain HTML, CSS, and JavaScript. GitHub Pages publishes this repository from the `main` branch root. The [use-case guide](docs/use-cases.html) covers six practical workflows with actual, reproducible outputs. Download the [output data](downloads/use-case-outputs.json) and [script](downloads/use_case_outputs.py) used to generate them. The downloadable Python wheel and source archive are in `downloads/`. The installable library source is also in [`library/`](library/).

[Real-data benchmarks](docs/benchmarks.html) compare the three trainable models on diabetes measurements, a social network, and historical sunspots. The [benchmark script](library/examples/benchmark_real_data.py), [results](library/examples/real-data-results.json), and data are versioned here. Run them from `library/` after installing the benchmark requirements.
