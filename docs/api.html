Documentation / API

API reference

Public objects are imported directly from orthopoly_applications. All models follow a fit then predict pattern.

Trainable models

Regression

PolynomialRegressor(family, degree, ridge=0.0)

fit(x, y) → self learns a one-dimensional response. predict(x) → ndarray evaluates it. family is a PolynomialFamily; coef_ holds learned basis coefficients. Chebyshev and Jacobi fits also expose domain_.

Classification

ChebyshevGraphClassifier(order=2, ridge=1e-3, max_iter=300)

fit(adjacency, features, labels, train_mask=None) → self learns from selected nodes. predict(...) → ndarray returns labels; predict_proba(...) → ndarray returns probabilities in classes_ order. Learned attributes include weights_, loss_, and n_iter_.

Forecasting

LaguerreForecaster(window, order, rate=1.0, horizon=1, ridge=1e-3, sample_spacing=1.0)

fit(values, train_end=None) → self trains on targets before the exclusive index train_end. predict_from_window(history) → float predicts from exactly window samples. predict_series(values) → (target_indices, predictions) returns aligned predictions. Learned parameters are coef_ and intercept_.

Classical polynomial basis

PolynomialFamily(kind, alpha=0.0, beta=0.0)

Supported kinds are jacobi, hermite, hermite_probabilists, chebyshev, and laguerre. Jacobi requires finite alpha, beta > -1; other families take no nonzero parameters.

  • evaluate(degree, x): evaluate a standard polynomial.
  • evaluate_series(coefficients, x): sum the basis series.
  • quadrature(order): Gaussian nodes and weights for the family weight.
  • norm_squared(degree): weighted squared norm.

project_function(function, family, degree, quadrature_order=None)

Project a vectorized callable to degrees 0..degree with Gaussian quadrature. Returns the weighted expansion coefficients. The callable must return one finite value per quadrature node.

Graph and signal utilities

normalized_laplacian(adjacency)

Return I - D^(-1/2) A D^(-1/2). Isolated nodes receive diagonal zero. Dense and SciPy sparse inputs are supported.

chebyshev_graph_filter(laplacian, features, coefficients, lambda_max=None)

Apply a fixed polynomial spectral filter by recurrence. For a normalized Laplacian, pass lambda_max=2 to skip estimating a largest eigenvalue.

chebyshev_smooth(values, degree)

Fit and return a low-degree Chebyshev trend for a uniformly spaced one-dimensional signal.

LaguerreExpansion.fit(times, values, order, rate=1.0)

Least-squares fit a sampled causal signal to finite-window Laguerre functions. Use reconstruct(times) to evaluate the fitted representation.

Orbit functions

cartan_matrix(type_name)

Return a Cartan matrix for A1, A2, B2, or G2.

WeylOrbit(cartan, weight)

Provide a dominant integral weight in fundamental-weight coordinates. orbit() returns distinct orbit weights and reflection-parity signs. evaluate(points, kind="C") evaluates C or S exponential sums at dual-coordinate points. S is zero on a reflection wall.

For definitions and normalization, see Mathematical conventions.
