01 / Diabetes measurements

The scikit-learn diabetes dataset has 442 observations. Orthopoly's regressor takes one scalar input, so every model below uses only the BMI feature to predict the supplied disease-progression target.

Method5-fold mean MAE ↓Interpretation
Orthopoly polynomial52.236Better than the mean, close to linear.
Linear regression51.955Lowest error in this comparison.
Training-set mean65.808Baseline with no BMI relationship.

Test design. Five seeded outer folds. Within each training fold, a separate 25% validation subset chooses polynomial degree 2–5 and ridge strength. The final outer test fold is not used to choose settings. Lower MAE is better.

02 / Karate Club network

Zachary's Karate Club is a recorded 34-person social network with two club factions. Each split reveals four members' labels per faction and scores the other 26. Node features are degree, clustering coefficient, and triangle count; they contain no faction labels.

MethodMean accuracy ↑Uses graph edges?
Orthopoly graph classifier64.8%Yes
Harmonic label propagation90.8%Yes
Feature-only logistic57.1%No
Training majority class50.0%No

Test design. Mean over 20 seeded label splits on the same graph. Edges and held-out node features are visible during training, while held-out labels are not. Label propagation is much stronger here; this small network does not establish how either method performs on other graphs.

03 / Yearly sunspots

The historical annual sunspot series covers 1700–2008. Models predict the next year's count using observations from previous years. The bundled CSV is the public-domain series distributed by statsmodels.

MethodTest RMSE ↓Test MAE ↓
Orthopoly Laguerre forecaster16.66413.773
Autoregressive ridge18.48115.377
Previous-year persistence30.43123.557

Test design. Train on targets through 1919, choose settings on 1920–1959, refit through 1959, and score 1960–2008 (49 years). Each prediction may use the previous observed year, including within the test period. This is rolling one-step evaluation, not a 49-year forecast made from 1959.

Reproduce and interpret

Install the optional benchmark packages, then run the Python script from the source archive. It reads a bundled sunspots CSV and datasets included with scikit-learn and NetworkX; it needs no dataset download at runtime.

Python · benchmark
python3 -m pip install -e .
python3 -m pip install -r examples/benchmark-requirements.txt
python3 examples/benchmark_real_data.py > examples/real-data-results.json

These results are limited to BMI as a single regression feature, one small social graph, and one historical time-series split. The full JSON includes each regression fold, each graph split, model settings, and every held-out sunspot forecast.
