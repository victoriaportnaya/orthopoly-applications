Getting started

Install the package, run a complete training example, and learn the input shapes before replacing the sample data with your own.

Requirements: Python 3.10 or newer, NumPy, and SciPy. The included training models do not require PyTorch.

Install

Work from the source directory for an editable installation:

Terminal
cd orthopoly_applications
python3 -m pip install -e .

You can also download the wheel and install the downloaded file:

Terminal
python3 -m pip install ./orthopoly_applications-0.1.0-py3-none-any.whl

The wheel contains the Python package. The source ZIP also includes examples, tests, documentation, and logo assets.

First training run

From the source directory, run the three application examples:

Terminal
python3 examples/train_applications.py
python3 -m unittest discover -s tests -v

The training script reports polynomial regression error, graph classification accuracy on unlabeled nodes, and forecast error on later time steps. Its data is synthetic and deterministic, so those scores demonstrate the workflow rather than real-world performance.

Input shapes

Polynomial regressionx: (samples,)y: (samples,)(new_samples,)

train_mask: (nodes,)		Labels per node or probabilities per class
Laguerre forecastsignal: (time_steps,)Future values derived by horizonTarget indices and predictions

Graph adjacency must be symmetric with finite, nonnegative weights; dense NumPy and SciPy sparse matrices are accepted. For forecasting, train_end is the first target index excluded from fitting.
