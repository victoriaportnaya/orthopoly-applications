Mathematical conventions

The standardizations behind the API matter when interpreting coefficients, moving between model families, or checking an identity.

Classical families

The package evaluates standard polynomials, not unit-normalized ones.

project_function computes each coefficient as <f,Pₙ> / ||Pₙ||² using Gaussian quadrature. For a general function, this is a numerical approximation to the weighted projection. The Jacobi integral in the coursework is a squared norm with a Kronecker delta, so the method is named norm_squared.

Graph scaling

For a normalized graph Laplacian L, its spectrum lies in [0,2]. The classifier forms graph features Tₖ(L-I)X for k=0..order using Chebyshev recurrence and matrix products. It then learns a softmax readout with cross-entropy and a ridge penalty on non-bias weights. The fixed chebyshev_graph_filter accepts another positive spectral upper bound when appropriate.

Laguerre history

At lag t ≥ 0 and rate a > 0, the function is φₙ(t)=√(2a) exp(-at) Lₙ(2at). These functions are orthonormal in the continuous inner product on [0,∞). The implementation works on sampled, finite windows. LaguerreExpansion fits sample values by least squares; LaguerreForecaster encodes histories and fits a future-value readout.

Weyl orbit sums

The C sum includes one complex exponential exp(2πi<μ,x>) for each distinct orbit point. The S sum multiplies terms by Weyl determinant signs for strictly dominant weights. For A1 and weight 1, this convention yields C₁(x)=2cos(2πx) and S₁(x)=2i sin(2πx). Weights use fundamental-weight coordinates; evaluation points use their dual coordinates.

Scope: orbit evaluation supports A1, A2, B2, and G2. The package does not implement a general discrete Weyl transform, character formula, root-lattice classifier, recurrent network, or dynamical-system model reduction.
