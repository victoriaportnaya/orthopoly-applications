Use cases

Six starting points for matching a data problem to a library method. The first three fit parameters from data; the others apply mathematical transforms.

Evidence: The included executable examples use synthetic data to show that the workflows run. They are not performance claims for a real application. Validate choices and report results on your own held-out data.

01 / Calibrate a measured response

Suppose an instrument gives a nonlinear output at different input levels. With paired scalar measurements x and y, PolynomialRegressor fits a low-degree curve, then predicts the response at new input values.

Input
Finite one-dimensional arrays of measured inputs and responses.
Result
Predictions and fitted basis coefficients.
Check
Choose degree and ridge strength on a validation split; report error on held-out measurements within the training range.

Run the regression example ↗ Chebyshev and Jacobi inputs are scaled to the training interval; outside values are extrapolations.

02 / Label a partly known network

Suppose a connected system has measurements at every node, but labels for only some nodes. Give the classifier an undirected adjacency matrix, node features, known labels, and a training mask. It builds Chebyshev graph features and learns a softmax readout from the labeled nodes.

Input
Symmetric nonnegative adjacency, a feature row per node, and at least two classes among labeled training nodes.
Result
Predicted labels or class probabilities for nodes on the same graph.
Check
Hold out labeled nodes for scoring. The graph and unlabeled node features remain visible during fitting, so evaluate it as a transductive method.

Run the node-classification example ↗ This implementation is a single polynomial layer with a linear readout, not a general deep GNN.

03 / Forecast the next reading

For a regularly sampled scalar series, LaguerreForecaster encodes a recent history window and fits a readout for a future sample. The horizon setting selects how many steps ahead to predict.

Input
One ordered, finite numerical signal with enough samples for the chosen window and horizon.
Result
Aligned target indices and forecast values, or one prediction from a history window.
Check
Split chronologically. Set train_end so future test targets never enter fitting; choose settings on an earlier validation interval.

Run the forecasting example ↗ The model uses sampled Laguerre features and a ridge readout; it is not a recurrent network.

04 / Transform values across connections

When each node in an undirected graph carries a value, apply a fixed Chebyshev filter to combine information according to the graph Laplacian. This is useful for experimenting with smoothing or other spectral responses chosen by coefficients.

Input
Symmetric nonnegative adjacency, node values or feature channels, and explicit filter coefficients.
Result
Transformed node values with the same shape as the input features.
Check
Inspect the effect of the chosen coefficients on representative graph signals. This utility does not learn coefficients from labels.

Start with the graph utility API ↗: compute normalized_laplacian(adjacency), then call chebyshev_graph_filter(laplacian, values, coefficients, lambda_max=2).

05 / Approximate a known function

If you can evaluate a function over the domain of a classical family, use weighted Gaussian quadrature to project it onto a finite polynomial basis. The result is a compact set of expansion coefficients that can be evaluated at new points.

Input
A vectorized callable, a supported polynomial family and weight, and a maximum degree.
Result
Weighted expansion coefficients for degrees zero through the chosen degree.
Check
Compare the reconstructed series with the original function on a grid. For noisy observations rather than a callable, use regression instead.

See basis and projection methods ↗ and the weight conventions ↗.

06 / Inspect mathematical symmetry

For supported root systems, construct a WeylOrbit from a dominant integral weight and evaluate its C or S exponential sum at dual-coordinate points. This supports exploration and visualization of orbit symmetry and reflection signs.

Input
An A1, A2, B2, or G2 Cartan matrix; a dominant weight; and points with the matching coordinate dimension.
Result
Orbit weights, parity signs, or complex-valued C/S sums.
Check
Verify the coordinate convention and compare known simple identities, such as the A1 cosine and sine sums.

See the orbit API ↗ and mathematical conventions ↗. This is a numerical symmetry tool, not a trained classifier.
