# Yearly sunspots data

`sunspots.csv` is the 309-row annual sunspot series for 1700–2008, copied from the [statsmodels dataset repository](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/datasets/sunspots/sunspots.csv). The [statsmodels dataset description](https://www.statsmodels.org/v0.13.5/datasets/generated/sunspots.html) attributes it to the National Geophysical Data Center and states that the data are public domain.
